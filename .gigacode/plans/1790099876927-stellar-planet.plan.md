# План: Вкладка "Планшет"

## Обзор
Реализовать вкладку "Планшет" — на неё можно добавлять карты из инвентаря (BagItem типа CARD). Карты не удаляются из инвентаря, а просто выбираются. У планшета есть ограничение на максимальное количество карт. У каждой карты на планшете можно увеличивать/уменьшать количество использований.

## Требования

### Модель данных
- **Новая сущность `TabletCard`** — таблица, хранящая связь между BagItem (картой в инвентаре) и планшетом
  - `id` — первичный ключ (autoGenerate)
  - `bagItemId` — FK на `bag_items.id` (ссылка на предмет в рюкзаке)
  - `uses` — текущее количество использований на планшете (Int, nullable)
- **Новая таблица** для хранения выбранных карт (не модифицирует инвентарь)

### UI
- Поле ввода максимального количества карт на планшете
- Список выбранных карт с кнопками +/- для использований
- Кнопка добавления карты из инвентаря (диалог с выбором из BagItem типа CARD)
- Кнопка удаления карты с планшета

## Детали реализации

### 1. Entity: TabletCard (`data/TabletCard.kt`)
```kotlin
@Entity(
    tableName = "tablet_cards",
    foreignKeys = [
        ForeignKey(
            entity = BagItem::class,
            parentColumns = ["id"],
            childColumns = ["bagItemId"],
            onDelete = ForeignKey.CASCADE
        )
    ],
    indices = [Index("bagItemId")]
)
data class TabletCard(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val bagItemId: Long,
    val uses: Int? = null
)
```

### 2. DAO: TabletCardDao (`data/TabletCardDao.kt`)
- `getAllWithBagItem(): Flow<List<TabletCardWithBagItem>>` — JOIN запрос с BagItem
- `insert(tabletCard: TabletCard): suspend Long`
- `delete(tabletCard: TabletCard): suspend Unit`
- `updateUses(id: Long, uses: Int): suspend Unit`
- `getByBagItemId(bagItemId: Long): suspend TabletCard?`
- `getAll(): Flow<List<TabletCard>>`

### 3. Data class для JOIN (`data/TabletCardWithBagItem.kt`)
```kotlin
data class TabletCardWithBagItem(
    @Embedded val tabletCard: TabletCard,
    @Relation val bagItem: BagItem
)
```

### 4. Repository (`data/TabletCardRepository.kt`)
- `tabletCards: StateFlow<List<TabletCardWithBagItem>>`
- `add(bagItemId: Long, uses: Int?)`
- `delete(tabletCard: TabletCard)`
- `updateUses(id: Long, uses: Int)`
- `countActive(): StateFlow<Int>` — текущее количество карт на планшете
- `maxCards: StateFlow<Int>` — максимальное количество (хранится как отдельная запись или в ViewModel)

### 5. ViewModel (`ui/tablet/TabletViewModel.kt`)
- `tabletCards: StateFlow<List<TabletCardWithBagItem>>`
- `maxCards: StateFlow<Int>`
- `currentCount: StateFlow<Int>`
- `setMaxCards(n: Int)`
- `addCard(bagItemId: Long, uses: Int?)` — если уже добавлена, обновляем uses
- `removeCard(tabletCard: TabletCard)`
- `changeUses(tabletCard: TabletCard, delta: Int)`

### 6. UI (`ui/tablet/TabletScreen.kt`)
```
Scaffold:
  - Top bar: "Планшет"
  - Body:
    - TextField: "Макс. карт" (числовое поле)
    - Divider
    - LazyColumn с картами:
      - TabletCardRow:
        - Название BagItem
        - Uses: [-] N [+]
        - Кнопка удаления
    - Empty state: "Нет выбранных карт"
  - FAB: "Добавить карту" → диалог выбора из инвентаря
```

**Диалог добавления:**
- Показывает все BagItem где `type == CARD`
- При выборе — проверяем `currentCount < maxCards`
- Если карта уже на планшете — просто обновляем uses
- Поле ввода initial uses в диалоге
